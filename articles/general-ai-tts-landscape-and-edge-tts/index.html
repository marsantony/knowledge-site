    AI TTS 生態與 YT 小說頻道的免費量產 pipeline

    重點¶

    • edge-tts 是「不付錢」的最大答案：rany2 寫的 Python 套件，逆向工程 Edge 朗讀的 WebSocket API，呼叫到的就是 Azure Neural TTS（曉曉、雲希、曉伊、曉晨等頂級神經語音），不需 Microsoft 帳號、不需 API key、無公開字數限制
    • 命令：edge-tts --voice zh-CN-XiaoxiaoNeural --text "..." --write-media out.mp3 --write-subtitles out.srt，直接輸出 mp3 + SRT 字幕
    • 三檔位實作：(1) 不寫程式 → 剪映/CapCut 內建 AI 朗讀；(2) 技術宅 → edge-tts + ffmpeg 批次；(3) 要差異化聲線 → GPT-SoVITS 本地克隆
    • 開源 TTS 商用三強：GPT-SoVITS（MIT、5 秒 zero-shot 克隆）、CosyVoice（Apache 2.0、情緒/方言控制最強）、F5-TTS。Fish-Speech 和 ChatTTS 因 license 問題不建議商用
    • 量產 pipeline：txt → Python 切章 → edge-tts 批次 → ffmpeg 合靜態圖 + 字幕 + BGM → youtube-upload 自動上傳，全自動、零成本、VPS 24 小時跑
    • 現成開源整合：Pixelle-Video（阿里）、火宝短剧，內建 edge-tts

    成本對照（一本 50 萬字小說）¶

    方案 成本
    ElevenLabs ~$300+ USD
    Azure 官方 SDK 第一個月 50 萬字免費，之後 ~$8 USD
    edge-tts $0，無上限
    GPT-SoVITS（本地） $0 + 顯卡電費 + 訓練時間

    SSML 多角色配音¶

    edge-tts 支援 SSML，能在同一個輸出裡切換音色做「多人配音」：

    <voice name="zh-CN-XiaoxiaoNeural">「你是誰？」她問。</voice>
<voice name="zh-CN-YunxiNeural">「我是路過的。」</voice>
<voice name="zh-CN-XiaoyiNeural">旁白繼續。</voice>

    旁白與對話分音色就能拉開與「單音色靜態圖」頻道的品質差距。

    風險¶

    • edge-tts 是反向工程，微軟可隨時改 API 把整套打死。重要商業案不該依賴
    • YT 對 AI 量產內容廣告變現審查越來越嚴（2024 起），純 TTS + 靜態圖很難開廣告
    • 網文版權：未授權直接讀的頻道很多，被檢舉下架是常態，比技術問題更要命
    • 聲音克隆名人/聲優：人格權民事風險，中國有實際告案

    開源 TTS 橫評¶

    模型 特色 License 適合
    GPT-SoVITS 5 秒 zero-shot 克隆、1 分鐘 fine-tune、跨語言 MIT 客製聲線
    CosyVoice（阿里） 情緒/方言/哭腔控制最強，支援 stream Apache 2.0 對話多、需要表演
    F5-TTS 速度快、流暢度好 商用 OK 短句
    Fish-Speech 訓練資料 72 萬小時、13 語言 License 收緊 不建議商用
    ChatTTS 對話場景優化 非商用 別用

    GPT-SoVITS 在中文圈最普及，有 Windows 一鍵整合包，雙擊 go-webui.bat 啟動 WebUI。

    雲端付費方案的位置¶

    魔音工坊、訊飛配音、九錘配音這類年費 200~900 人民幣的服務，主要客群是：(1) 短影音團隊不想搞技術 (2) 要商用級正版授權 (3) 要真人錄音庫。在「不想付錢」這條路上不重要。

    背景¶

    研究 YT 小說朗讀頻道實際用什麼 TTS 技術。原本以為是「CP 值高的付費服務」，深入查才發現整個生態是建立在 edge-tts 這套完全免費的反向工程方案上——絕大多數每天上傳幾集的量產頻道根本不付錢。

    技術選型的關鍵是區分兩個場景： - 離線批次生成（YT 頻道做法）：edge-tts 一條龍最香，品質直接對標 Azure Neural - 線上即時朗讀（網頁閱讀器做法）：Web Speech API 純前端、零成本、零延遲

    兩條路的工具完全不同。
