    Claude Code 官方依賴清單與內建 ripgrep 代理機制

    重點¶

    • 必要依賴：Git、Shell（Bash / Zsh / PowerShell / CMD 任一）
    • 強烈建議：ripgrep（rg）— Claude Code 已 vendor 內建，但 Alpine、WSL 跨檔案系統等情境可能需要系統版本作為 fallback
    • Windows 特例：原生 Windows 用戶必裝 Git for Windows，否則 Claude Code 會降級到 PowerShell，許多 Bash 工具不可用
    • rg 在 Claude Code 環境會被定義為 shell function，代理到 claude binary 內建的 ripgrep（透過 ARGV0=rg 重設 argv[0]），用 type rg 可驗證
    • 用 type <cmd> 檢查指令真實形態（function / alias / file），比 which 更完整
    • 官方文件沒有明文要求 jq、gh、fd、bat 等工具——這些是社群常用配套，不是 Claude Code 本身的依賴

    背景¶

    確認 Claude Code 官方文件實際列出的依賴，並查清自己環境是否齊全。網路上常見的「Claude Code 必裝工具」清單往往把社群偏好混進官方需求，要看官方文件才準確。

    官方明文依賴（來自 docs.claude.com）¶

    等級 工具 用途
    必要 Git 版本控制與整合
    必要 Shell Bash / Zsh / PowerShell / CMD
    強烈建議 ripgrep 程式碼搜尋、@file 引用、自訂 agent / skill 檔案查找
    Win 必要 Git for Windows 提供 Bash 工具組（不裝會降級到 PowerShell）

    可選整合：VS Code 擴充、JetBrains 外掛、MCP server（GitHub、Google Drive、Gmail 等）、Python / Node.js（跑自訂 MCP 才需要）。

    rg 的 shell function 代理機制¶

    裝完 Claude Code 後在 bash 跑 type rg，會看到 rg 不是 binary 也不是 alias，而是個 function：

    rg () {
    local _cc_bin="${CLAUDE_CODE_EXECPATH:-}"
    [[ -x $_cc_bin ]] || _cc_bin=$HOME/.local/bin/claude   # 實際是硬編碼絕對路徑
    if [[ ! -x $_cc_bin ]]; then
        command rg "$@"
        return
    fi
    if [[ -n $ZSH_VERSION ]]; then
        ARGV0=rg "$_cc_bin" "$@"
    else
        # bash / 其他: 用 exec -a 重設 argv[0]
        if [[ $BASHPID != $$ ]]; then
            exec -a rg "$_cc_bin" "$@"
        else
            ( exec -a rg "$_cc_bin" "$@" )
        fi
    fi
}

    關鍵設計： - 把 rg 代理到 claude 執行檔 - 透過 ARGV0=rg 或 exec -a rg 重設 argv[0]，讓 claude binary 從自己的入口判斷「現在要當 ripgrep 用」 - 內部 dispatch 到 vendor 的 ripgrep - 找不到 claude binary 時 fallback 到 command rg

    實務影響： - 使用者環境不需要另外裝 ripgrep，Claude Code 自帶 - 但仍建議系統裝一份作 fallback（特別是 Alpine / WSL 跨 /mnt/c/ 情境） - which rg 看不到這層代理，要用 type rg

    環境檢查指令¶

    一行檢查所有相關工具：

    for cmd in git bash rg gh jq fd node python3 uv curl; do
    printf "%-12s" "$cmd"
    command -v $cmd >/dev/null && echo "✓ $($cmd --version 2>&1 | head -1)" || echo "✗ 未安裝"
done

    注意 Ubuntu 的 fd 套件指令叫 fdfind，需要 symlink：ln -s $(which fdfind) ~/.local/bin/fd。
