    FF14 潛水艇攻略：開圖、練級、畢業配置

    重點¶

    • 畢業配置首推 3124 不改（85 級），跑溺沒海 OJ 撈首飾，4 艘日收約 40-45 萬系統金
    • 練級路線：1111 → (25 級) 3113 → (50 級進灰海) 1123 → (85 級) 3124 不改
    • 開圖是純機率，與潛水艇屬性無關，1111 就能從頭開到尾
    • 改級幾乎不值得：3124 改和不改跑 OJ 收益相同，改級反而維修費更高（24 vs 10 修理材料），回本時間以年計算
    • 收艇節奏比配置重要：把航線時間湊到自己能上線的時段（一天/一天半/兩天），比追求最高單位時間經驗更實際

    配件命名與屬性¶

    配件命名：[船體-船尾-船首-艦橋]，1=鯊魚級、2=甲鲎級、3=鬚鯨級、4=腔棘魚級、5=希爾德拉級。

    五項屬性：探索（掉落檔位）、收集（掉落數量品質）、航速（返航時間）、航距（可到達點位）、恩惠（bonus 經驗/HQ）。

    四維和公式：SUM = RANK × 5 + 75（RANK 為配件等級，改級視為 6 級）。

    每 10 級提升的屬性接近一套全改的提升量，所以「等升級再換不改」通常優於「提前換改級」。

    溺沒海開圖（1-50 級，約 45-55 天）¶

    主線路徑：B → E → J → N → O → S → T → Y → Z → AA → AB → AD → 灰海A

    關鍵解鎖節點： - J 點：第 2 艘潛水艇 - O 點：第 3 艘潛水艇 - T 點：第 4 艘潛水艇

    常見致命錯誤：走岔路導致一直開不出 J/O/T，務必查 Wiki 海圖確認路線。

    開圖策略： - 前段（只有 1 艘）：一天一收，同時跑主線+支線末端 - 中段（2-3 艘）：第 1 艇單點開圖，其他艇按練級表跑 - 後段（4 艘齊全）：第 1 艇單點開圖（3123 跑單點 T 起），其他自行練級

    等級與配置對照：

    等級 推薦配置 說明
    1-20 1111 收集最高，bonus 經驗好
    20-25 1121 需要 75 航距時換上
    25-50 3113 收集+恩惠極高，經驗效率遠超其他

    灰海練級（50-85 級）¶

    主線：A → B → C → F → G → H → K → L → P → R → 翠浪海A

    核心觀念： - 灰海經驗效率遠高於溺沒海，練級+開圖可兼顧 - 跑 4-5 點練級路線順帶包含要開的圖即可 - 不進翠浪海的玩家只需開到 K 點

    配置建議： - 一天半航線：3123（如 ACGF、ACGH） - 兩天航線：1123（如 BACFD、ACFGD）

    翠浪海與妖歌海（80 級以上，可選）¶

    翠浪海經驗效率與灰海幾乎無差，唯一目的是進妖歌海。85 級就跑 OJ 的玩家完全不需要開。

    妖歌海 90 級以上經驗效率最高，練級用 1123 不改或 3123 全改。

    畢業配置經濟學¶

    判斷標準：任何收益期望低於 10 萬/日/船的配置，不如換 3124 撈首飾賣錢再買。

    改級值不值得的計算：提前畢業天數 × 10萬 ≥ 改級成本 → 值得。

    練級配件值得投資的：0003（3 級艦橋），半日航線每艘提前 9 天畢業，整日航線提前 13.5 天，只要物價不離譜就穩賺。

    配件成本評估原則： - 畢業配置用到的配件 → 0 成本 - 從親友借來的 → 0 成本 - 能賣二手的 → 按折舊價算 - 能用多遍的 → 除以使用次數
